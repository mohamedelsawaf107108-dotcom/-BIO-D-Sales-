# BIO-D Sales
نسخة أولى تعمل في المتصفح، للموبايل والكمبيوتر.

## التشغيل
افتح dist/index.html أو انشر مجلد dist على GitHub Pages. زر تسجيل الدخول يفتح مساحة العمل المحلية مباشرة.

## الرفع على GitHub
1. فك ضغط الملف.
2. أنشئ مستودعاً جديداً وارفع محتويات مجلد المشروع بما فيها dist و .github.
3. من Settings ثم Pages اختر GitHub Actions.
4. من Actions شغّل Deploy BIO-D Sales، ثم افتح رابط النشر.

## الموجود
العملاء وأرصدة البداية، الزيارات ونتائجها ومواعيد المتابعة، المنتجات والأسعار، طلبات البيع وحالاتها وتاريخ الاستحقاق، التحصيل الجزئي وإثبات الدفع والمراجعة المحلية، المستحقات، فرص البيع، الخطة وتارجت البيع والتحصيل، التقارير اليومية والأسبوعية والشهرية والربع سنوية والسنوية، الطباعة وحفظ PDF ومشاركة التقرير، لوحة متابعة، GPS واتجاهات Google Maps، نسخ احتياطي واستعادة JSON.

## حدود النسخة
- البيانات في متصفح الجهاز عبر localStorage. الدخول حالياً يفتح مساحة عمل محلية، ويحتاج نظام الحسابات والصلاحيات والمزامنة بين المناديب والإدارة إلى خادم وقاعدة بيانات مشتركة.
- اعتماد التحصيل محلي ويمكن لمستخدم الجهاز تغييره، لذلك هذه النسخة للتجربة. توجد معالجة حفظ واستعادة ومرفقات بحد ١٫٥ ميجابايت للصورة. احتفظ بنسخ احتياطية.
- إدخال بيانات GPS يتطلب HTTPS وإذن الموقع. ترتيب الزيارات تقريبي بالمسافة الجغرافية من نقطة البداية. حساب المرور ومواعيد العملاء وتحسين عدد الزيارات يحتاج خدمة توجيه لاحقاً. الاتجاهات تفتح في Google Maps.
- أرصدة العملاء إجمالية. توزيع الدفعات على فواتير محددة والإشعارات التلقائية وترتيب أداء المناديب يحتاج استكمالاً.
- التقارير تعرض الأرقام الفعلية للفترة المختارة، وتعرض تارجت وخطة الفترات المتداخلة بالكامل مع تواريخها دون توزيع نسبي.
- مشاركة التقارير تفتح قائمة المشاركة عندما يدعمها الجهاز وإلا تحمّل ملفاً نصياً. اختيار المستلم والإرسال يتمان بواسطة المستخدم.
- صورة المزرعة توضيحية مولّدة، والشعار من المستخدم.
